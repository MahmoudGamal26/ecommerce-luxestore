# 🛒 LuxeCart - منصة المتجر الإلكتروني الفاخر (E-Commerce Platform)

مشروع متجر إلكتروني متكامل واحترافي مصمم بأحدث تقنيات الويب، مع لوحة تصفح وسلة تسوق تفاعلية، نظام فلاتر متقدم، خصومات أكواد التخفيض، ونظام إتمام طلبات شاسع مع سيرفر API خلفي مبني بلغة Python.

---

## 🌟 الميزات الرئيسية (Key Features)

1. **تصميم عصري وتفاعلي (Modern & Responsive UI)**:
   - دعم كامل للغة العربية والواجهة من اليمين لليسار (RTL).
   - وضع ليلي ونهاري سلس (Dark/Light Mode).
   - متوافق تماماً مع جميع الشاشات (الهواتف، التابلت، الشاشات الكبيرة).

2. **إدارة المنتجات والفلاتر (Product Catalog & Filtering)**:
   - تصنيف المنتجات حسب الفئات (إلكترونيات، أزياء، ديكور، ملحقات).
   - بحث فوري وسريع بالاسم أو الوصف.
   - ترتيب المنتجات حسب السعر والتقييم والموصى به.
   - نافذة العرض السريع (Quick View Modal) مع قائمة المواصفات والمعرض.

3. **سلة التسوق ونظام الخصومات (Cart & Coupons)**:
   - سلة تسوق جانبية منزلقة (Slide-Over Cart Drawer).
   - حفظ تلقائي لعناصر السلة والمفضلة في ذاكرة المتصفح (localStorage).
   - نظام أكواد خصم تفاعلي (أكواد تجريبية: `SAVE20` لخصم 20%، `LUXE10` لخصم 10%).

4. **إتمام الطلبات (Checkout & Invoice)**:
   - نموذج إتمام طلبات متعدد الخيارات (بطاقة ائتمانية / دفع عند الاستلام).
   - إصدار فاتورة طلب ورقم مرجعي فريد تلقائياً.

5. **سيرفر API خلفي (Python Backend Server)**:
   - خفيف وسريع وبدون أي مكتبات خارجية متطلبة (`server.py`).
   - يوفر Endpoints لـ `/api/products`, `/api/coupon`, `/api/checkout`.

## 🚀 طريقة التشغيل (Quick Start)

### التشغيل بكليك واحد على Windows:
قم بنقر دبل كليك على ملف **`run.bat`** في مجلد المشروع، وسيتم فتح السيرفر تلقائياً على الرابط:
👉 **`http://localhost:8000`**

### التشغيل عبر أسطر الأوامر (Terminal / Command Prompt):
```bash
python server.py
```
ثم افتح متصفحك وادخل على `http://localhost:8000`.
